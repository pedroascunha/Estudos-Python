# Projeto: Python + GitHub Copilot

Projeto pequeno para praticar Python usando GitHub Copilot.

Estrutura:

- `src/basico.py`: funções básicas (soma, média, palíndromo).
- `src/copilot_exemplos.py`: funções pensadas para treinar o Copilot.
- `tests/test_basico.py`: testes automatizados com pytest.
